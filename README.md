# Elektro Eva – Planá

Jednoduchý, moderní a responzivní web pro obchod **Elektro Eva** v Plané (náměstí Svobody 3).

## Co web obsahuje

- Úvodní stránka s kontaktem
- Sekce O nás
- Sortiment (elektrospotřebiče, elektronika, domácí potřeby, Fotolab)
- Otevírací doba
- Kontakt + mapa

## Technologie

- Čisté HTML
- Tailwind CSS (přes CDN)
- Font Awesome ikony
- Vhodné pro GitHub Pages

## Nasazení na GitHub Pages

1. Nahrajte složku do GitHub repozitáře
2. V Settings → Pages nastavte zdroj na `main` branch a root (`/`)
3. Web bude dostupný na `https://vas-username.github.io/nazev-repo/`
